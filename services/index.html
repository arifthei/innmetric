Distribution Baseline Audit

Purpose. Create an evidence-backed view of the current commercial setup before anyone changes it.

Scope

  • System and channel map
  • Live sellability tests under recorded conditions
  • Room-type and rate-plan structure review
  • Availability, restriction and inventory review
  • Mapping and derived-rate checks
  • Direct-channel and OTA comparison
  • Promotion, meal-plan, tax and policy consistency review
  • Reservation-flow checks where access permits
  • Priority assessment based on commercial impact, risk and effort

Outputs

  • Baseline report
  • Evidence register
  • Confirmed findings and unresolved hypotheses
  • Root-cause notes where access supports a conclusion
  • Prioritized correction backlog
  • Proposed QA test for each recommended change

The baseline does not promise a revenue increase. It establishes what can be proved and what needs controlled remediation.

Approved Repair Sprint

Purpose. Implement a defined group of corrections without losing control of the current setup.

Scope

  • Confirmed change list
  • Named hotel approver
  • Risk level for each change
  • Before-state evidence
  • Change execution inside agreed systems
  • Rollback note where required
  • Post-change system check
  • Live guest-facing verification
  • Issue closure record

Typical work

  • Repairing room and rate-plan mappings
  • Correcting availability or restriction logic
  • Restoring derived-rate relationships
  • Aligning occupancy, meal-plan or refundability rules
  • Correcting OTA listing fields and room content
  • Reviewing promotion conflicts
  • Validating reservation delivery after a configuration change

InnMetric applies only named and approved actions. Vendor development work, unsupported API changes and changes outside granted access require a separate scope.

Ongoing Distribution Control

Purpose. Prevent known commercial controls from drifting after the baseline and repair work.

Possible cadence

  • Daily review for agreed high-risk items
  • Weekly pickup, pricing and channel review
  • Weekly mapping, restriction and promotion checks
  • Monthly distribution and net ADR review
  • Scheduled direct-booking and OTA journey tests
  • Change log review
  • Recurrence reporting

Outputs

  • Weekly action record
  • Pricing and distribution decisions with ownership
  • Exception list
  • Verified fixes
  • Monthly performance and control summary

The cadence is defined in the contract. InnMetric does not claim continuous automated monitoring unless the agreed tools support it.

Selective Public Distribution Snapshot

InnMetric may prepare a short public snapshot before a commercial conversation. It records one observable difference under stated test conditions. The snapshot cannot prove the internal cause, intent or exact financial effect. Those questions belong in the paid baseline.
